---
title: Product Data Schema
---

The product data schema below lists all available fields in a product record.  Note that actual product records (actually, most of them) may not have every field present.

<ResponseField name="asins" field-type="keyword">
  The ASIN (Amazon identifier) used for this product.


  **Example:** `"asins":  "B0009XCFRE"`
</ResponseField>

<ResponseField name="brand" field-type="text">
  The brand name of this product as presented by the data source.


  **Example:** `"brand": "Sumsung Electronics"`
</ResponseField>

<ResponseField name="categories" field-type="text">
  A list of category keywords used for this product across multiple sources.

  **Example:**
  ```json
  "categories": [
     "Home Improvement",
     "Heating, Cooling, & Air Quality",
     "Heaters",
     "Propane Heaters"
   ]
  ```
</ResponseField>

<ResponseField name="canonicalBrand" field-type="text">
  The canonical brand name after normalization of the name from the source.


  **Example:** `"canonicalBrand": "Sumsung"`
</ResponseField>

<ResponseField name="colors" field-type="text">
  A list of colors available for this product.

  **Example:**
  ```json
  "colors": [
     "White",
     "Black"
   ]
  ```
</ResponseField>

<ResponseField name="count" field-type="keyword">
  The number of units included in the product packaging.  Can include a description of the unit.


  **Example:** `"count": "30"`
</ResponseField>

<ResponseField name="dateAdded" field-type="date">
  The date this product was first added to the product database.


  **Example:** `"dateAdded": "2017-01-08T19:12:13Z"`
</ResponseField>

<ResponseField name="dateUpdated" field-type="date">
  The most recent date this product was updated or seen by our system.


  **Example:** `"dateUpdated": "2017-01-08T19:12:13Z"`
</ResponseField>

<ResponseField name="descriptions" field-type="nested">
  A list of descriptions for this product from various sources.  Each description contains:

  **Example:**
  ```json
  "descriptions": [
     {
       "dateSeen": "2017-01-08T19:12:13Z",
       "sourceURLs": [    "https://www.domain.com/p/123"
       ],
       "value": "Now you can enjoy cooking
   your favorite food."
     },
     {
       "sourceURLs": [
    "http://www.website.com/4567"
       ],
       "value": "The Worthington Pro Grade 20 lb.
   Empty Propane Tank goes with your gas barbecue grill
   (sold separately) and accommodates 4.7 gallons of gas."
     }
   ]
  ```

  <Expandable title="Sub-fields">
    <ResponseField name="descriptions.dateSeen" field-type="date">
      The date when this description has been seen selling this product.
    </ResponseField>
    <ResponseField name="descriptions.sourceURLs" field-type="keyword">
      A list of source URLs where this specific description was seen.
    </ResponseField>
    <ResponseField name="descriptions.value" field-type="text">
      A unique description for this product.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="dimension" field-type="keyword">
  The length, width, and height of this product.  Units included.
   [Dimensions Normalization](/docs/dimensions-normalization)

  **Example:**
  ```json
  "dimension": "23 in x 43.7 in x 30 in",`
   `"dimension": "16 ft x 22 ft",`
   `"dimension": "15 mm x 42 mm x 34 mm"
  ```
</ResponseField>

<ResponseField name="domains" field-type="domain">
  A list of each unique domain found in the `sourceURLs` field.

  **Example:**
  ```json
  "domains": [
     "www.domain.com",
     "www.website.com"
   ]
  ```
</ResponseField>

<ResponseField name="ean" field-type="keyword">
  The EAN codes for this product.  There may be more than one EAN in the list when a product has multiple variations,
    each using a different EAN.
     [Learn more about EANs](https://en.wikipedia.org/wiki/International_Article_Number).

  **Example:**
  ```json
  "ean": [
     "0014045125963",
     "0014045125965"
   ]
  ```
</ResponseField>

<ResponseField name="ean13" field-type="keyword">
  The EAN-13 code for this product.    [Learn more about EANs](https://en.wikipedia.org/wiki/International_Article_Number).


  **Example:** `"ean13":"0014045125963"`
</ResponseField>

<ResponseField name="ean8" field-type="keyword">
  The EAN-8 code for this product.    [Learn more about EANs](https://en.wikipedia.org/wiki/International_Article_Number).


  **Example:** `"ean8":"96385074"`
</ResponseField>

<ResponseField name="features" field-type="nested">
  A list of features associated with this product.  The feature list can be collected from specific feature sections available on product listings for the product.  It can also serve as a catch-all field for miscellaneous characteristics of this product that don't make sense to include as top-level fields.
  
   Each feature contains:

  **Example:**
  ```json
  "features": [
     {
       "key": "Count",
       "replace": "true",
       "value": [
         "1"
       ]
     },
     {
       "key": "Included",
       "value": [
         "Batteries"
       ]
     }
   ]
  ```

  <Expandable title="Sub-fields">
    <ResponseField name="features.key" field-type="text">
      A label for this feature.
    </ResponseField>
    <ResponseField name="features.replace" field-type="boolean">
      Flag indicating value field is replaced versus appended.
    </ResponseField>
    <ResponseField name="features.value" field-type="text">
      A list of possible values for this feature.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="financingAndLeasing" field-type="text">
  A list of financing or leasing terms associated with this product.  Each term may contain:

  **Example:**
  ```json
  "financingAndLeasing": [
     {
       "additionalDetails": [
         "acquisitionFee: $925",
         "mileOverageFee: $0.30/mile"
       ],
       "apr": 4.15,
       "currency": "USD",
       "dateSeen": [
         "2018-09-20T04:00:00Z"
       ],
       "description": "Well equipped with features",
       "disclaimers": "Offer not valid in Puerto Rico.
   Lease financing available",
       "dueAtSigningMax": 7694,
       "dueAtSigningMin": 7694,
       "milesPerYear": 22500,
       "monthlyPaymentMax": 1269,
       "monthlyPaymentMin": 1269,
       "name": "2018 Civic Si Coupe 6
   Speed Manual Featured Special Lease",
       "offerStartDate": "2018-10-31T00:00:00.000Z",
       "offerEndDate": "2018-09-05T00:00:00.000Z",
       "term": "36 months",
       "type": "leasing",
       "securityDepositMax": 0,
       "securityDepositMin": 0,
       "sourceURLs": [
       ]
     }
   ]
  ```

  <Expandable title="Sub-fields">
    <ResponseField name="financingAndLeasing.additionalDetails" field-type="text">
      Any additional information related to this term.
    </ResponseField>
    <ResponseField name="financingAndLeasing.apr" field-type="text">
      The annual percentage rate.
    </ResponseField>
    <ResponseField name="financingAndLeasing.currency" field-type="keyword">
      The currency listed for any monetary values.
    </ResponseField>
    <ResponseField name="financingAndLeasing.dateSeen" field-type="date">
      A list of dates when this term was seen.
    </ResponseField>
    <ResponseField name="financingAndLeasing.description" field-type="text">
      The description provided for this term.
    </ResponseField>
    <ResponseField name="financingAndLeasing.disclaimers" field-type="text">
      Any disclaimers associated with this term.
    </ResponseField>
    <ResponseField name="financingAndLeasing.dueAtSigningMax" field-type="float">
      The maximum monetary amount due when purchasing this product under this term.
    </ResponseField>
    <ResponseField name="financingAndLeasing.dueAtSigningMin" field-type="float">
      The minimum monetary amount due when purchasing this product under this term.
    </ResponseField>
    <ResponseField name="financingAndLeasing.milesPerYear" field-type="float">
      Usually associated with vehicles, the maximum mileage allowed under this term.
    </ResponseField>
    <ResponseField name="financingAndLeasing.monthlyPaymentMax" field-type="float">
      The maximum amount due each month under this term.
    </ResponseField>
    <ResponseField name="financingAndLeasing.monthlyPaymentMin" field-type="float">
      The minimum amount due each month under this term.
    </ResponseField>
    <ResponseField name="financingAndLeasing.name" field-type="text">
      The name for this term.
    </ResponseField>
    <ResponseField name="financingAndLeasing.type" field-type="keyword">
      Either `financing` or `leasing`.
    </ResponseField>
    <ResponseField name="financingAndLeasing.securityDepositMax" field-type="float">
      The maximum security deposit for this term.
    </ResponseField>
    <ResponseField name="financingAndLeasing.securityDepositMin" field-type="float">
      The minimum security deposit for this term.
    </ResponseField>
    <ResponseField name="financingAndLeasing.sourceURLs" field-type="keyword">
      A list of URLs where this term was seen.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="flavors" field-type="text">
  A list of flavors available for this product.

  **Example:**
  ```json
  "flavors": [
     "Fruit Punch",
     "Berry",
     "Grape"
   ]
  ```
</ResponseField>

<ResponseField name="gtins" field-type="keyword">
  A list of all Global Trade Identifier Numbers for this product. Values will include all ean, isbn, and upc values.
    [Learn more about GTINs](https://en.wikipedia.org/wiki/Global_Trade_Item_Number).

  **Example:**
  ```json
  "gtins": [
     "0014045125963",
     "0014045125965",
     "014045125963",
     "014045125961",
     "425261",
     "3882215542"
   ]
  ```
</ResponseField>

<ResponseField name="imageURLs" field-type="keyword">
  A list of image URLs for this product.

  **Example:**
  ```json
  "imageURLs": [
     "https://i5.images.com/asr.jpeg"
   ]
  ```
</ResponseField>

<ResponseField name="isbn" field-type="keyword">
  The ISBN code for this product.  [Learn more about ISBNs](https://en.wikipedia.org/wiki/International_Standard_Book_Number).


  **Example:** `"isbn": "3882215542"`
</ResponseField>

<ResponseField name="keys" field-type="keyword">
  A list of internal Datafiniti identifiers for this product.  The `keys` field is used to merge raw data from individual sources into the master Datafiniti record.  [Learn how this works](/docs/how-product-records-are-merged)

  **Example:**
  ```json
  "keys": [
     "014045125963",
     "0014045125963",
     "worthington/299581"
   ]
  ```
</ResponseField>

<ResponseField name="manufacturer" field-type="text">
  The manufacturer of this product.


  **Example:** `"manufacturer": "Worthington"`
</ResponseField>

<ResponseField name="manufacturerNumber" field-type="keyword">
  The manufacturer or model number of this product.


  **Example:** `"manufacturerNumber": "299581"`
</ResponseField>

<ResponseField name="merchants" field-type="nested">
  A list of merchants selling this product.  These are typically third-party merchants found on e-commerce websites.
  
   Merchant objects can contain:

  **Example:**
  ```json
  "merchants": [
     {
       "address": "2801 S Ih 35",
       "availability": "...",
       "city": "Austin",
       "country": "US",
       "dateSeen": "2017-01-08T19:12:13Z",
       "isPrivateSeller": false
       "name": "Zappysales",
       "phone": "5127131234",
       "postalCode": "78701",
       "province": "TX"
     },
     {
       "dateSeen": [
         "2017-01-08T19:12:13Z"
       ],
       "name": "Next Day Mro, Llc"
     }
    ]
  ```

  <Expandable title="Sub-fields">
    <ResponseField name="merchants.address" field-type="text">
      The merchant's physical address.
    </ResponseField>
    <ResponseField name="merchants.availability" field-type="keyword">
      A description of the product's availability with this merchant.
    </ResponseField>
    <ResponseField name="merchants.city" field-type="text">
      The merchant's city.
    </ResponseField>
    <ResponseField name="merchants.dateSeen" field-type="date">
      The date when this merchant has been seen selling this product.
    </ResponseField>
    <ResponseField name="merchants.isPrivateSeller" field-type="boolean">
      True if the merchant is an individual. False if it's a company.
    </ResponseField>
    <ResponseField name="merchants.name" field-type="text">
      The merchant's name.
    </ResponseField>
    <ResponseField name="merchants.phone" field-type="keyword">
      The merchant's phone number.
    </ResponseField>
    <ResponseField name="merchants.postalCode" field-type="text">
      The merchant's postal or zip code.
    </ResponseField>
    <ResponseField name="merchants.province" field-type="text">
      The merchant's province or state.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="mostRecentPriceAmount" field-type="float">
  The product's most recent price amount scraped.


  **Example:** `"mostRecentPriceAmount": 85`
</ResponseField>

<ResponseField name="mostRecentPriceAvailability" field-type="text">
  The product's most recent price availability scraped.


  **Example:** `"mostRecentPriceAvailability": "true"`
</ResponseField>

<ResponseField name="mostRecentPriceByDomain" field-type="nested">
  A list of Prices of this product by each domain source.  These are typically third-party merchants found on e-commerce websites.

  **Example:**
  ```json
  "mostRecentPriceByDomain": [
                   {
                       "amount": 79.95,
                       "availability": "true",
                       "currency": "USD",
                       "isSale": "true",
                       "domain": "www.nordstrom.com",
                       "sourceURL": "https://www.nordstrom.com/s/sea-level-multifit-cross-front-bikini-top/5746068",
                       "date": "2022-03-29T16:43:23.440Z",
   "firstDateSeen": "2022-03-29T16:59:38.617Z"
                       ],
                   },
                   {
                       "amount": 89.95,
                       "availability": "true",
                       "currency": "USD",
                       "isSale": "false",
                       "domain": "www.sephora.com",
                       "sourceURL": "https://www.sephora.com/s/5746068",
                       "date": "2022-03-29T16:40:43.440Z"
                   }
               ]
  ```

  <Expandable title="Sub-fields">
    <ResponseField name="mostRecentPriceByDomain.amount" field-type="text">
      The price amount of the product by this domain.
    </ResponseField>
    <ResponseField name="mostRecentPriceByDomain.availability" field-type="keyword">
      A true or false if this product is available at this price.
    </ResponseField>
    <ResponseField name="mostRecentPriceByDomain.currency" field-type="text">
      The currency listed for amount.
    </ResponseField>
    <ResponseField name="mostRecentPriceByDomain.color" field-type="keyword">
      The color associated with this price.
    </ResponseField>
    <ResponseField name="mostRecentPriceByDomain.condition" field-type="keyword">
      The condition of the product when being sold at this price.
    </ResponseField>
    <ResponseField name="mostRecentPriceByDomain.date" field-type="date">
      The date when this price was seen.
    </ResponseField>
    <ResponseField name="mostRecentPriceByDomain.domain" field-type="domain">
      The domain sourceURL of the product's price
    </ResponseField>
    <ResponseField name="mostRecentPriceByDomain.firstDateSeen" field-type="date">
      the date of when the record was first scraped by Datafiniti
    </ResponseField>
    <ResponseField name="mostRecentPriceByDomain.isSale" field-type="boolean">
      A true/false for whether or not this price is a sale/discounted price.
    </ResponseField>
    <ResponseField name="mostRecentPriceByDomain.size" field-type="text">
      The size associated with this price.
    </ResponseField>
    <ResponseField name="mostRecentPriceByDomain.sourceURLs" field-type="text">
      A list of URLs
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="mostRecentPriceColor" field-type="text">
  The most recent color(s) available for this product.


  **Example:** `"mostRecentPriceColor": "Torrid - coral with shimmer"`
</ResponseField>

<ResponseField name="mostRecentPriceCondition" field-type="keyword">
  The condition most recently scrape of the product when being sold at this price.


  **Example:** `"condition": "Used",`
</ResponseField>

<ResponseField name="mostRecentPriceCurrency" field-type="text">
  The currency listed for mostRecentPriceAmount.


  **Example:** `"mostRecentPriceCurrency": "USD"`
</ResponseField>

<ResponseField name="mostRecentPriceDate" field-type="date">
  The most recent price date of the product record.


  **Example:** `"mostRecentPriceDate": "2022-03-29T19:26:49.157Z"`
</ResponseField>

<ResponseField name="mostRecentPriceDomain" field-type="domain">
  The domain of the most recent price scraped by Datafiniti


  **Example:** `"mostRecentPriceDomain": "www.nordstrom.com"`
</ResponseField>

<ResponseField name="mostRecentPriceIsSale" field-type="boolean">
  A true/false for whether or not this price is a sale/discounted price.


  **Example:** `"mostRecentPriceIsSale": "true"`
</ResponseField>

<ResponseField name="mostRecentPriceSize" field-type="text">
  The size associated with this mostRecentPrice.


  **Example:** `"mostRecentPriceSize": "M"`
</ResponseField>

<ResponseField name="mostRecentPriceSourceURL" field-type="keyword">
  The most recent URL used to generate data for this product.

  **Example:**
  ```json
  "mostRecentPriceSourceURL": "https://www.nordstrom.com/s/ara-gloria-gore-tex-waterproof-bootie-women/5684497"
  ```
</ResponseField>

<ResponseField name="name" field-type="text">
  The product's name.


  **Example:** `"name": "Worthington 20-lb Tank"`
</ResponseField>

<ResponseField name="prices" field-type="nested">
  A list of prices for this product.
  
   Price objects may contain:

  **Example:**
  ```json
  "prices": [
     {
       "amountMin": 59.96,
       "amountMax": 59.96,
       "availability": "true",
       "color": "Red",
       "condition": "New",
       "count": "15",
       "currency": "USD",
       "dateSeen": [
         "2016-06-10T00:00:00Z"
       ],
       "flavor": "Cherry",
       "isSale": "false",
       "isSold": "false",
       "merchant": "domain.com",
       "offer": "22% off",
       "returnPolicy": "90-Day",
       "shipping": "FREE shipping",
       "size": "S",
       "sourceURLs": [
         "https://www.domain.com/p/123",
        "warranty": "..."
       ]
     },
     {
       "amountMin": 62.06,
       "amountMax": 72.06,
       "condition": "new",
       "currency": "USD",
       "dateSeen": [
         "2016-10-28T00:00:00Z"
       ],
       "merchant": "MRO - website.com",
       "sourceURLs": [
         "http://www.website.com/4567"
       ]
     }
   ]
  ```

  <Expandable title="Sub-fields">
    <ResponseField name="prices.amountMin" field-type="float">
      The minimum price value listed.
    </ResponseField>
    <ResponseField name="prices.amountMax" field-type="float">
      The maximum price value listed.  This is typically the same as amountMin, except in cases where a price range is listed.
    </ResponseField>
    <ResponseField name="prices.availability" field-type="keyword">
      A true or false if this product is available at this price.
    </ResponseField>
    <ResponseField name="prices.color" field-type="keyword">
      The color associated with this price.
    </ResponseField>
    <ResponseField name="prices.condition" field-type="keyword">
      The condition of the product when being sold at this price.
    </ResponseField>
    <ResponseField name="prices.count" field-type="keyword">
      The number of units being sold at this price.
    </ResponseField>
    <ResponseField name="prices.currency" field-type="text">
      The currency listed for amountMin and amountMax.
    </ResponseField>
    <ResponseField name="prices.dateSeen" field-type="date">
      A list of dates when this price was seen.
    </ResponseField>
    <ResponseField name="prices.flavor" field-type="keyword">
      The flavor associated with this price.
    </ResponseField>
    <ResponseField name="prices.isSale" field-type="boolean">
      A true/false for whether or not this price is a sale/discounted price.
    </ResponseField>
    <ResponseField name="prices.isSold" field-type="boolean">
      A true/flase for whether or not the product has been sold at this price (typically reserved for vehicle listings).
    </ResponseField>
    <ResponseField name="prices.merchant" field-type="keyword">
      The merchant and/or website selling at this price.
    </ResponseField>
    <ResponseField name="prices.offer" field-type="text">
      Any special offer associated with this price.
    </ResponseField>
    <ResponseField name="prices.returnPolicy" field-type="text">
      The return policy associated with this price.
    </ResponseField>
    <ResponseField name="prices.shipping" field-type="text">
      The shipping terms associated with this price.
    </ResponseField>
    <ResponseField name="prices.size" field-type="text">
      The size associated with this price.
    </ResponseField>
    <ResponseField name="prices.sourceURLs" field-type="keyword">
      A list of URLs where this price was seen.
    </ResponseField>
    <ResponseField name="prices.warranty" field-type="text">
      The warranty associated with this price.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="primaryCategories" field-type="text">
  A list of standardized categories to which this product belongs.  Category values can be found [here](/docs/possible-values-for-product-fields).

  **Example:**
  ```json
  "primaryCategories": [
     "Electronics"
   ]
  ```
</ResponseField>

<ResponseField name="primaryImageURLs" field-type="keyword">
  A list of URLs for the primary images taken from each domain sourced in this record.  This list will only contain 1 URL per domain.

  **Example:**
  ```json
  "primaryImageURLs: [
      "https://www.amazon.com/i/123.jpg"
     "https://www.target.com/i/abc.jpg"
   ]
  ```
</ResponseField>

<ResponseField name="quantities" field-type="nested">
  A list of available quantities for this product.  Quantities indicate how many units of the product are available from a specific source at a given time.
  
   Quantity objects may contain:

  **Example:**
  ```json
  "quantities": [
     {
       "dateSeen": [
         "2013-06-02T16:00:00Z",
         "2014-05-01T14:00:00Z"
       ],
       "sourceURLs": [
         "http://www.website.com/4567"
       ],
       "value": 20
     }
   ]
  ```

  <Expandable title="Sub-fields">
    <ResponseField name="quantities.dateSeen" field-type="date">
      A list of dates when this quantity was seen.
    </ResponseField>
    <ResponseField name="quantities.sourceURLs" field-type="keyword">
      A list of URLs where this quantity was seen.
    </ResponseField>
    <ResponseField name="quantities.value" field-type="text">
      The actual quantity value.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="reviews" field-type="nested">
  A list of reviews for this product.
  
   Review objects may contain:

  **Example:**
  ```json
  "reviews": [
     {
       "date": "2015-06-16T00:00:00Z",
       "dateSeen": "2016-05-15T00:00:00Z",
       "didPurchase": true,
       "doRecommend": true,
       "id": "1234"
       "numHelpful": 4,
       "rating": 4,
       "sourceURLs": [
           "http://www.website.com/4567"
       ],
       "text": "Nice tank at a below
   average cost for propane tanks.",
       "title": "Solid Propane Tank",
       "userCity": "...",
       "username": "Cole33",
       "userProvince": "..."
     },
     {
       "date": "2015-01-06T00:00:00Z",
       "dateSeen": [
         "2016-05-15T00:00:00Z"
       ],
       "rating": 5,
       "sourceURLs": [
           "https://www.domain.com/p/123"
         ],
       "text": "Holds propane and does not leak.
   Completed the given gift.",
       "title": "tanked",
       "username": "joel01"
     }
   ]
  ```

  <Expandable title="Sub-fields">
    <ResponseField name="reviews.date" field-type="date">
      The date the review was posted.
    </ResponseField>
    <ResponseField name="reviews.dateSeen" field-type="date">
      The date when the review was seen by Datafiniti.
    </ResponseField>
    <ResponseField name="reviews.didPurchase" field-type="boolean">
      A true/false for whether or not the reviewer did purchase the product.
    </ResponseField>
    <ResponseField name="reviews.doRecommend" field-type="boolean">
      A true/false for whether or not the reviewer recommends the product.
    </ResponseField>
    <ResponseField name="reviews.id" field-type="keyword">
      The website ID associated with this review.
    </ResponseField>
    <ResponseField name="reviews.numHelpful" field-type="integer">
      The number of people that found this review helpful.
    </ResponseField>
    <ResponseField name="reviews.rating" field-type="float">
      A 1 to 5 start value for the review.
    </ResponseField>
    <ResponseField name="reviews.sourceURLs" field-type="keyword">
      A list of URLs where this review was seen.
    </ResponseField>
    <ResponseField name="reviews.text" field-type="text">
      The full (or available) text of the review.

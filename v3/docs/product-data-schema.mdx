---
title: Product Data Schema
---

The product data schema below lists all available fields in a product record.  Note that actual product records (actually, most of them) may not have every field present.

<ResponseField name="asins" field-type="text">
  A list of ASINs (Amazon identifiers) used for this product.

  **Example:**
  ```json
  "asins": [
     "B0009XCFRE"
   ]
  ```
</ResponseField>

<ResponseField name="brand" field-type="text">
  The brand name of this product.


  **Example:** `"brand": "Worthington"`
</ResponseField>

<ResponseField name="categories" field-type="text">
  A list of category keywords used for this product across multiple sources.

  **Example:**
  ```json
  "categories": [
     "Home Improvement",
     "Heating, Cooling, & Air Quality",
     "Heaters",
     "Propane Heaters"
   ]
  ```
</ResponseField>

<ResponseField name="colors" field-type="text">
  A list of colors available for this product.

  **Example:**
  ```json
  "colors": [
     "White",
     "Black"
   ]
  ```
</ResponseField>

<ResponseField name="count" field-type="text">
  The number of units included in the product packaging.


  **Example:** `"count": 1`
</ResponseField>

<ResponseField name="dateAdded" field-type="text">
  The date this product was first added to the product database.


  **Example:** `"dateAdded": "2017-01-08T19:12:13Z"`
</ResponseField>

<ResponseField name="dateUpdated" field-type="text">
  The most recent date this product was updated or seen by our system.


  **Example:** `"dateUpdated": "2017-01-08T19:12:13Z"`
</ResponseField>

<ResponseField name="descriptions" field-type="nested">
  A list of descriptions for this product from various sources.  Each description contains:

  **Example:**
  ```json
  "descriptions": [
     {
       "dateSeen": [
         "2017-01-08T19:12:13Z"
       ]
       "sourceURLs": [
         "https://www.domain.com/p/123"
       ],
       "value": "Now you can enjoy cooking your favorite food."
     },
     {
       "sourceURLs": [
         "http://www.website.com/4567"
       ],
       "value": "The Worthington Pro Grade 20 lb. Empty Propane Tank goes with your gas barbecue grill (sold separately) and accommodates 4.7 gallons of gas."
     }
   ]
  ```

  <Expandable title="Sub-fields">
    <ResponseField name="descriptions.dateSeen" field-type="text">
      A list of dates when this description has been seen selling this product.
    </ResponseField>
    <ResponseField name="descriptions.sourceURLs" field-type="text">
      A list of source URLs where this specific description was seen.
    </ResponseField>
    <ResponseField name="descriptions.value" field-type="text">
      A unique description for this product.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="dimension" field-type="text">
  The length, width, and height of this product.  Units included.


  **Example:** `"dimension": "23 in x 43.7 in x 30 in"`
</ResponseField>

<ResponseField name="ean" field-type="text">
  The EAN codes for this product.  There may be more than one EAN in the list when a product has multiple variations,
    each using a different EAN.
     [Learn more about EANs](https://en.wikipedia.org/wiki/International_Article_Number).

  **Example:**
  ```json
  "ean": [
     "0014045125963",
     "0014045125965"
   ]
  ```
</ResponseField>

<ResponseField name="features" field-type="nested">
  A list of features associated with this product.  The feature list can be collected from specific feature sections available on product listings for the product.  It can also serve as a catch-all field for miscellaneous characteristics of this product that don't make sense to include as top-level fields.
  
   Each feature contains:

  **Example:**
  ```json
  "features": [
     {
       "key": "Count",
       "value": [
         "1"
       ]
     },
     {
       "key": "Dimensions",
       "value": [
         "12.5 x 12.5 x 18.5 in"
       ]
     }
   ]
  ```

  <Expandable title="Sub-fields">
    <ResponseField name="features.key" field-type="text">
      A label for this feature.
    </ResponseField>
    <ResponseField name="features.value" field-type="text">
      A list of possible values for this feature.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="flavors" field-type="text">
  A list of flavors available for this product.

  **Example:**
  ```json
  "flavors": [
     "Fruit Punch",
     "Berry",
     "Grape"
   ]
  ```
</ResponseField>

<ResponseField name="imageURLs" field-type="text">
  A list of image URLs for this product.

  **Example:**
  ```json
  "imageURLs": [
     "https://i5.images.com/asr.jpeg"
   ]
  ```
</ResponseField>

<ResponseField name="isbn" field-type="text">
  The ISBN code for this product.  [Learn more about ISBNs](https://en.wikipedia.org/wiki/International_Standard_Book_Number).


  **Example:** `"isbn": "3882215542"`
</ResponseField>

<ResponseField name="keys" field-type="text">
  A list of internal Datafiniti identifiers for this product.  The `keys` field is used to merge raw data from individual sources into the master Datafiniti record.  [Learn more about how this works](https://datafiniti.co).

  **Example:**
  ```json
  "keys": [
     "014045125963",
     "0014045125963",
     "worthington/299581"
   ]
  ```
</ResponseField>

<ResponseField name="manufacturer" field-type="text">
  The manufacturer of this product.


  **Example:** `"manufacturer": "Worthington"`
</ResponseField>

<ResponseField name="manufacturerNumber" field-type="text">
  The manufacturer or model number of this product.


  **Example:** `"manufacturerNumber": "299581"`
</ResponseField>

<ResponseField name="merchants" field-type="nested">
  A list of merchants selling this product.  These are typically third-party merchants found on e-commerce websites.
  
   Merchant objects can contain:

  **Example:**
  ```json
  "merchants": [
     {
       "address": "2801 S Ih 35",
       "availability": "...",
       "city": "Austin",
       "country": "US",
       "dateSeen": [
         "2017-01-08T19:12:13Z"
       ],
       "isPrivateSeller": "false"
       "name": "Zappysales",
       "phone": "5127131234",
       "postalCode": "78701",
       "province": "TX"
     },
     {
       "dateSeen": [
         "2017-01-08T19:12:13Z"
       ],
       "name": "Next Day Mro, Llc"
     }
    ]
  ```

  <Expandable title="Sub-fields">
    <ResponseField name="merchants.address" field-type="text">
      The merchant's physical address.
    </ResponseField>
    <ResponseField name="merchants.availability" field-type="text">
      A description of the product's availability with this merchant.
    </ResponseField>
    <ResponseField name="merchants.city" field-type="text">
      The merchant's city.
    </ResponseField>
    <ResponseField name="merchants.dateSeen" field-type="text">
      A list of dates when this merchant has been seen selling this product.
    </ResponseField>
    <ResponseField name="merchants.isPrivateSeller" field-type="text">
      True if the merchant is an individual. False if it's a company.
    </ResponseField>
    <ResponseField name="merchants.name" field-type="text">
      The merchant's name.
    </ResponseField>
    <ResponseField name="merchants.phone" field-type="text">
      The merchant's phone number.
    </ResponseField>
    <ResponseField name="merchants.postalCode" field-type="text">
      The merchant's postal or zip code.
    </ResponseField>
    <ResponseField name="merchants.province" field-type="text">
      The merchant's province or state.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="name" field-type="text">
  The product's name.


  **Example:** `"name": "Worthington 20-lb Tank"`
</ResponseField>

<ResponseField name="prices" field-type="nested">
  A list of prices for this product.
  
   Price objects may contain:

  **Example:**
  ```json
  "prices": [
     {
       "amountMin": 59.96,
       "amountMax": 59.96,
       "availability": "...",
       "color": "...",
       "condition": "New",
       "count": "...",
       "currency": "USD",
       "dateAdded": "2017-01-08T19:12:13Z",
       "dateSeen": [
         "2016-06-10T00:00:00Z"
       ],
       "flavor": "...",
       "isSale": "false",
       "isSold": "false",
       "merchant": "domain.com",
       "offer": "22% off",
       "returnPolicy": "90-Day",
       "shipping": "FREE shipping",
       "size": "...",
       "sourceURLs": [
         "https://www.domain.com/p/123",
        "warranty": "..."
       ]
     },
     {
       "amountMin": 62.06,
       "amountMax": 72.06,
       "condition": "new",
       "currency": "USD",
       "dateAdded": "2017-01-08T19:12:13Z",
       "dateSeen": [
         "2016-10-28T00:00:00Z"
       ],
       "merchant": "MRO - website.com",
       "sourceURLs": [
         "http://www.website.com/4567"
       ]
     }
   ]
  ```

  <Expandable title="Sub-fields">
    <ResponseField name="prices.amountMin" field-type="text">
      The minimum price value listed.
    </ResponseField>
    <ResponseField name="prices.amountMax" field-type="text">
      The maximum price value listed.  This is typically the same as amountMin, except in cases where a price range is listed.
    </ResponseField>
    <ResponseField name="prices.availability" field-type="text">
      The product's availability at this price.
    </ResponseField>
    <ResponseField name="prices.color" field-type="text">
      The color associated with this price.
    </ResponseField>
    <ResponseField name="prices.condition" field-type="text">
      The condition of the product when being sold at this price.
    </ResponseField>
    <ResponseField name="prices.currency" field-type="text">
      The currency listed for amountMin and amountMax.
    </ResponseField>
    <ResponseField name="prices.dateAdded" field-type="text">
      The date this price was first added to the prices list.
    </ResponseField>
    <ResponseField name="prices.dateSeen" field-type="text">
      A list of dates when this price was seen.
    </ResponseField>
    <ResponseField name="prices.flavor" field-type="text">
      The flavor associated with this price.
    </ResponseField>
    <ResponseField name="prices.isSale" field-type="text">
      A true/false for whether or not this price is a sale/discounted price.
    </ResponseField>
    <ResponseField name="prices.isSold" field-type="text">
      A true/flase for whether or not the product has been sold at this price (typically reserved for vehicle listings).
    </ResponseField>
    <ResponseField name="prices.merchant" field-type="text">
      The merchant and/or website selling at this price.
    </ResponseField>
    <ResponseField name="prices.offer" field-type="text">
      Any special offer associated with this price.
    </ResponseField>
    <ResponseField name="prices.returnPolicy" field-type="text">
      The return policy associated with this price.
    </ResponseField>
    <ResponseField name="prices.shipping" field-type="text">
      The shipping terms associated with this price.
    </ResponseField>
    <ResponseField name="prices.sourceURLs" field-type="text">
      A list of URLs where this price was seen.
    </ResponseField>
    <ResponseField name="prices.warranty" field-type="text">
      The warranty associated with this price.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="quantities" field-type="nested">
  A list of available quantities for this product.  Quantities indicate how many units of the product are available from a specific source at a given time.
  
   Quantity objects may contain:

  **Example:**
  ```json
  "quantities": [
     {
       "dateSeen": [
         "2013-06-02T16:00:00Z",
         "2014-05-01T14:00:00Z"
       ],
       "sourceURLs": [
         "http://www.website.com/4567"
       ],
       "value": 20
     }
   ]
  ```

  <Expandable title="Sub-fields">
    <ResponseField name="quantities.dateSeen" field-type="text">
      A list of dates when this quantity was seen.
    </ResponseField>
    <ResponseField name="quantities.sourceURLs" field-type="text">
      A list of URLs where this quantity was seen.
    </ResponseField>
    <ResponseField name="quantities.value" field-type="text">
      The actual quantity value.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="reviews" field-type="nested">
  A list of reviews for this product.
  
   Review objects may contain:

  **Example:**
  ```json
  "reviews": [
     {
       "date": "2015-06-16T00:00:00Z",
       "dateAdded": "2017-01-08T19:12:13Z",
       "dateSeen": [
         "2016-05-15T00:00:00Z"
       ],
       "didPurchase": true,
       "doRecommend": true,
       "id": "1234"
       "numHelpful": 4,
       "rating": 4,
       "sourceURLs": [
           "http://www.website.com/4567"
       ],
       "text": "Nice tank at a below average cost for propane tanks.",
       "title": "Solid Propane Tank",
       "userCity": "...",
       "username": "Cole33",
       "userProvince": "..."
     },
     {
       "date": "2015-01-06T00:00:00Z",
       "dateAdded": "2017-01-08T19:12:13Z",
       "dateSeen": [
         "2016-05-15T00:00:00Z"
       ],
       "rating": 5,
       "sourceURLs": [
           "https://www.domain.com/p/123"
         ],
       "text": "Holds propane and does not leak. Completed the given gift.",
       "title": "tanked",
       "username": "joel01"
     }
   ]
  ```

  <Expandable title="Sub-fields">
    <ResponseField name="reviews.date" field-type="text">
      The date the review was posted.
    </ResponseField>
    <ResponseField name="reviews.dateAdded" field-type="text">
      The date the review was added to Datafiniti.
    </ResponseField>
    <ResponseField name="reviews.dateSeen" field-type="text">
      A list of dates when the review was seen by Datafiniti.
    </ResponseField>
    <ResponseField name="reviews.didPurchase" field-type="text">
      A true/false for whether or not the reviewer did purchase the product.
    </ResponseField>
    <ResponseField name="reviews.doRecommend" field-type="text">
      A true/false for whether or not the reviewer recommends the product.
    </ResponseField>
    <ResponseField name="reviews.id" field-type="text">
      The website ID associated with this review.
    </ResponseField>
    <ResponseField name="reviews.numHelpful" field-type="text">
      The number of people that found this review helpful.
    </ResponseField>
    <ResponseField name="reviews.rating" field-type="text">
      A 1 to 5 start value for the review.
    </ResponseField>
    <ResponseField name="reviews.sourceURLs" field-type="text">
      A list of URLs where this review was seen.
    </ResponseField>
    <ResponseField name="reviews.text" field-type="text">
      The full (or available) text of the review.
    </ResponseField>
    <ResponseField name="reviews.title" field-type="text">
      The review's title.
    </ResponseField>
    <ResponseField name="reviews.userCity" field-type="text">
      The reviewer's city.
    </ResponseField>
    <ResponseField name="reviews.username" field-type="text">
      The reviewer's username.
    </ResponseField>
    <ResponseField name="reviews.userProvince" field-type="text">
      The reviewer's province or state.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sizes" field-type="text">
  A list of sizes available for this product.

  **Example:**
  ```json
  "sizes": [
     "Large",
     "Medium",
     "Small"
   ]
  ```
</ResponseField>

<ResponseField name="skus" field-type="nested">
  A list of SKUs for this product.  SKUs are typically specific to individual retailers or websites.
  
   SKU objects may contain:

  **Example:**
  ```json
  "skus": [
     {
       "sourceURLs": [
         "http://www.web.com/p/123"
       ],
       "value": "1234XK6"
     }
   ]
  ```

  <Expandable title="Sub-fields">
    <ResponseField name="skus.sourceURLs" field-type="text">
      A list of URLs where this SKU was seen.
    </ResponseField>
    <ResponseField name="skus.value" field-type="text">
      The actual SKU.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="sourceURLs" field-type="text">
  A list of URLs used to generate data for this product.

  **Example:**
  ```json
  "sourceURLs": [
     "https://www.domain.com/p/123",
     "http://www.website.com/4567"
   ]
  ```
</ResponseField>

<ResponseField name="upc" field-type="text">
  The UPC code for this product.
     There may be more than one UPC in the list when a product has multiple variations,
    each using a different UPC.  [Learn more about UPCs](https://en.wikipedia.org/wiki/Universal_Product_Code).

  **Example:**
  ```json
  "upc": [
     "014045125963",
     "014045125961"
   ]
  ```
</ResponseField>

<ResponseField name="vin" field-type="text">
  The VIN code for this product.  This is specific to car listings.  [Learn more about VINs](https://en.wikipedia.org/wiki/Vehicle_identification_number).


  **Example:** `"vin": "1FTMF1ET8EFB00361"`
</ResponseField>

<ResponseField name="websiteIDs" field-type="text">
  A list of website IDs for this product.  Website IDs are tied to a specific online retailer.  They are the unique identifier used by website.  They are used by Datafiniti when other unique identifiers are not available for a product.

  **Example:**
  ```json
  "websiteIDs": [
     "domain.com-123",
     "website.com-4567"
   ]
  ```
</ResponseField>

<ResponseField name="weight" field-type="text">
  The weight of the product.  Units included.


  **Example:** `"weight": "20 lbs"`
</ResponseField>
